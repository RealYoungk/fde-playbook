# 화면 점검표

## 내용
- [ ] 첫 화면에 결론 한 줄과 선택 안의 KPI가 보인다
- [ ] 모든 수치에 기존안 대비 변화가 있다
- [ ] 단위가 붙어 있다 (분, %, 개, 명, 대)
- [ ] 지표마다 "높을수록/낮을수록 좋음"과 관련 이해관계자가 있다
- [ ] 가정과 출처(담당자 발언 번호)가 화면 어딘가에 있다
- [ ] 미확정 결정이 표시돼 있다
- [ ] 데모 문구, 더미 데이터, 영어 placeholder가 남아 있지 않다

## 시각
- [ ] 강조색 1개, 상태색 2개 이내
- [ ] 간격이 스케일(4, 8, 12, 16, 24, 32)을 따른다
- [ ] 숫자는 tabular-nums, 표 숫자 오른쪽 정렬
- [ ] 외부 폰트, 외부 CDN 없음
- [ ] 카드 중첩 없음, 그림자 과하지 않음

## 상태
- [ ] 빈 데이터, 오류, 해 없음 화면이 있다
- [ ] 파라미터 극단값에서 깨지지 않는다
- [ ] 긴 이름과 많은 행에서 레이아웃이 버틴다

## 접근성
- [ ] 입력에 label, 표에 th scope, SVG에 aria-label
- [ ] 키보드 Tab으로 모든 조작 가능, 포커스 보임
- [ ] 색 외의 단서(+/- 기호, 태그 글자)
- [ ] 390px 폭에서 깨지지 않음
