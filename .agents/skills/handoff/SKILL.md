# 인계 (handoff)

자동 요약(compact)에 맡기지 않고 명시적으로 인계 문서를 남긴다. 다른 사람이나 다음 세션이 이어받을 수 있게 남겼는지도 평가 대상이다.

## 언제
- 서면 합의 직후, 최소 동작 버전 완성 직후, 검토 세션 전
- 대화가 길어져 응답이 이전 결정을 잊기 시작할 때

## `docs/work/HANDOFF.md` 갱신 (덮어쓰기, 1화면 분량)
```
# HANDOFF (갱신: HH:MM, 경과 NN분)
## 목표와 합의
- AGREEMENT.md 요지 3줄, 성공 기준 숫자
## 현재 상태
- 동작하는 것 / 미완성 / 알려진 버그
- 실행: (명령)
## 최근 결정 (DECISIONS.md 번호)
- D5, D6, D7 요지
## 다음 세션의 첫 행동
1. (구체적인 한 가지)
## 주의
- 건드리면 안 되는 것, 미확인 가정
```

## 순서
1. HANDOFF.md 갱신
2. `git add -A && git commit -m "handoff: <단계>"`
3. 새 세션이 필요하면 `/new` 후 첫 지시: "AGENTS.md와 docs/work/HANDOFF.md를 읽고 '다음 세션의 첫 행동'부터 진행해. 시작 전에 이해한 내용을 3줄로 요약하고 멈춰."
