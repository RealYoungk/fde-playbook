# 결정 카드

담당자는 요구사항을 처음부터 다 말해주지 않는다. 만드는 쪽이 결정해야 할 것을 먼저 찾아서, **고르기만 하면 되는 형태**로 내밀어야 요구가 나온다.
좋은 카드는 담당자가 10초 안에 답할 수 있고, 답하지 않아도 작업이 멈추지 않는다(기본값이 있다).

## 1. 결정 포인트 찾기 (구현 중 상시)
아래 신호가 보이면 결정 포인트다. 에이전트는 코드에 임의 값을 박기 전에 멈추고 `docs/work/OPEN_DECISIONS.md`에 카드로 올린다.
- 숫자 상수를 정해야 할 때 (거리 기준, 정원, 버퍼 시간, 목표 커버율)
- 두 목표가 충돌할 때 (편의 vs 비용, 정확도 vs 속도)
- 예외를 어떻게 할지 (데이터 결측, 교대 근무, 소수 인원 구역)
- 누구를 위해 무엇을 보여줄지 (화면 기본 정렬, 강조 지표)
- 범위를 넣을지 뺄지
- 담당자 발언이 두 가지로 해석될 때

## 2. 카드 형식
```
### C3. 도보 허용 기준 [상태: 대기 | 기본값으로 진행 중 | 확정]
왜 필요: 보관함이 "덮는" 직원 범위를 정해야 보관함 수와 커버율이 결정됨
선택지:
  A. 3분: 3분 내 비율 81%, 보관함 12곳 필요 (이용 편의 우선)
  B. 5분: 5분 내 비율 78%, 보관함 5곳 (비용 우선)
  C. 화면에서 바꿔 보며 비교 (둘 다 제시)
추천: C, 기본값은 A. 담당자 발언 "멀면 그냥 책상으로 보내달라고 함"(Q3) 근거
영향 받는 사람: 이용 직원(도보 거리), 재무(보관함 수)
답이 없으면: A로 진행하고 화면에서 바꿀 수 있게 둠
```
규칙
- 선택지는 2~3개. 각 선택지에 **결과 숫자**를 붙인다(가능하면 실제 계산값). 숫자가 없으면 "예상"이라고 표시.
- 추천과 근거(담당자 발언 번호, 데이터)를 붙인다. 추천 없는 카드는 결정을 떠넘기는 것이다.
- 기본값을 반드시 적는다. 답을 기다리느라 멈추지 않는다.
- 한 카드에 결정 하나.

## 3. 묶어서 보내기
- 대기 중인 카드를 영향 큰 순으로 3~5개씩 묶어 한 메시지로 보낸다.
- 메시지 첫 줄에 진행 상황 한 줄 ("v0 화면이 나왔고, 아래 3가지만 정해주시면 확정하겠습니다").
- 담당자용 문장은 짧게, 기술 용어 없이. 선택지는 A/B/C로 답할 수 있게.
```
현재 기존안 대비 3분 내 이용 가능 인원이 40% → 81%로 늘어나는 안까지 만들었습니다. 아래 세 가지만 골라주시면 반영하겠습니다.

1) 도보 기준: A. 3분 (보관함 12곳) / B. 5분 (보관함 5곳) / C. 둘 다 비교 화면으로 → 추천 C
2) 야간 근무자: A. 경비실 수령 유지 / B. 야간동 보관함 추가 → 추천 A (야간 47명, 관행 유지)
3) 보관함 수 상한: 재무팀에서 정한 숫자가 있을까요? 없으면 현재 8곳 기준으로 두겠습니다.
```

## 3-1. 메시지 품질 (워크슬롭 금지)
- AI가 쓴 긴 글을 그대로 보내지 않는다. 받는 사람이 다시 읽고 정리해야 하는 글은 비용 전가다.
- 첫 줄에 핵심(진행 상황 또는 요청), 나머지는 짧은 번호 목록. 각 항목에 내 추천과 근거 한 줄.
- 담당자가 물은 것에는 데이터가 아니라 **내 판단**으로 먼저 답하고, 근거 숫자를 붙인다.

## 4. 답을 받으면
- 원문을 `QUESTIONS.md`에, 결정을 `DECISIONS.md`에 D번호로 옮기고 카드 상태를 "확정"으로.
- 확정값은 코드의 기본 파라미터와 `Constraint.source`에 반영한다 (출처: C3, 담당자 답변).
- 답이 기존 가정을 뒤집으면 영향 받는 화면과 지표를 다시 계산해 Before/After로 보여준다.
- 담당자가 앞선 답을 바꾸면 스트레스 받지 말고 바뀐 이유(진짜 목표)를 묻고, 그 목표 기준으로 다음 카드를 우리가 먼저 제안한다.

## 5. 화면에서 결정 드러내기 (빨간 펜 받기)
- 미확정 결정과 연결된 파라미터는 화면에서 조절 가능하게 두고 "담당자 확인 대기"로 표시한다.
- 시나리오 비교표 자체가 결정 카드다. 각 열이 선택지, 각 행이 결과 숫자.
- 결정권자가 다를 수 있는 항목(예: 예산)은 화면에 "재무 확인 필요"처럼 누가 정해야 하는지 적는다.

## 6. 서술형에서
"요구사항이 불명확했을 때 어떻게 했나"의 답 재료가 된다: 몇 개의 결정 포인트를 찾았고, 어떤 기본값으로 진행했고, 담당자 답으로 무엇이 바뀌었나.
