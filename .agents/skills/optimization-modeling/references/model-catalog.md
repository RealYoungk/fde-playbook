# 모델 카탈로그

표기: 수요 i ∈ I (가중치 w_i), 후보 j ∈ J, 비용 c_ij, 커버 여부 a_ij = [c_ij ≤ T]

## 최대 커버리지 (MCLP)
- 변수: x_j ∈ {0,1} 후보 개설, y_i ∈ {0,1} 수요 커버
- 최대화 Σ w_i y_i
- 제약: y_i ≤ Σ_j a_ij x_j, Σ x_j ≤ p, (유지할 기존 지점) x_j = 1
- 주의: 덮이지 않은 수요는 무시되므로 꼬리 지표(T 초과 인원)를 같이 본다

## 최소 개수 커버 (부분 집합 커버)
- 최소화 Σ x_j
- 제약: y_i ≤ Σ_j a_ij x_j, Σ w_i y_i ≥ α Σ w_i (α=목표 커버율)
- α=1이면 덮을 수 있는 수요 전부. 덮을 수 없는 수요(어떤 후보와도 T 초과)는 따로 보고

## p-median
- 변수: x_j, z_ij ∈ [0,1] (배정)
- 최소화 Σ w_i c_ij z_ij
- 제약: Σ_j z_ij = 1, z_ij ≤ x_j, Σ x_j = p, (선택) c_ij > T이면 z_ij = 0
- 평균은 좋아지지만 먼 소수가 남을 수 있다. 최대 비용 제약을 같이 고려

## 용량 제약 배정
- 변수: z_ij ∈ {0,1}
- 최소화 Σ c_ij z_ij, 제약: Σ_j z_ij = 1, Σ_i d_i z_ij ≤ K_j
- 예: 사람을 시간대(정원)에, 회의를 방에, 작업을 담당자에

## 차량 경로 (VRP)
- OR-Tools Routing. 노드 0 = 차고지(또는 도착지). 용량, 최대 운행 시간, 시간창, 정차 시간
- 도착형 경로: 도착지를 depot으로 두고 경로를 뒤집어 읽으면 "지점들 → 도착지"
- 결과: 경로별 지점 순서, 적재량, 소요 시간 → `timetable.backward_schedule`로 시각표

## 시간표
- 도착 목표 시각(근무 시작 - 버퍼)에서 구간 소요시간과 정차 시간을 빼며 역산
- 근무 시작 시각이 여러 개면 `shift_waves`로 회차를 묶고, 회차마다 수요를 다시 계산

## 군집과 후보 생성
- 가중 k-means 중심 = 수요 밀집 위치. k는 상한 개수의 1.5~3배로 넉넉히 만든 뒤 MCLP로 고른다
- 실제 설치 가능 위치와 다를 수 있음을 가정으로 기록

## 교차검증 방법
- 작은 사례(후보 8개 이하) 완전탐색과 MIP 목적값 일치
- MIP ≥ 탐욕 (최대화), MIP ≤ 탐욕 (최소화)
- Dart 구현과 Python 구현이 같은 규칙의 탐욕에서 같은 선택을 내는지
- 해를 독립 채점 함수로 다시 계산해 솔버 목적값과 일치하는지
